# Point Landing

Самостоятельный статический лендинг. Главная, страницы пунктов, партнёров,
продавцов, условия, калькуляторы, презентации и RU/EN/中文 сохранены.
Базы, авторизации и API здесь нет.

## Запуск

Node >= 22.13.0; внешних зависимостей нет.

```powershell
Copy-Item .env.example .env.local
npm run dev
```

Если .env.local существует, не перезаписывать его командой копирования.
Адрес: http://localhost:5173/. После правок обновить браузер; страницы читаются с диска.
APP_URL задаёт origin приложения, по умолчанию https://app.2point.ru.
Для рабочего сайта, например: https://app.2point.ru.
Регистрация, кабинет, маркет и согласие открываются в приложении.
Папка app для работы/сборки лендинга не требуется.

## Сборка

```powershell
npm run build
npm start
```

dist/ — готовый статический сайт, npm start — просмотр именно dist локально.
Страницы имеют index.html в папках маршрутов, например points/conditions/index.html.
Хостинг должен поддерживать directory index. APP_URL встраивается при сборке;
при смене рабочего адреса пересобрать.

## Структура

- pages/ — исходный HTML без визуальной переработки.
- public/ — CSS, изображения, JS, переводы и документы. Полный набор статических
  файлов сохранён для предотвращения потери оформления. Старый CSS кабинета
  не добавляет кабинет или API в лендинг.
- scripts/site.mjs — карта страниц, APP_URL, преобразование ссылок.
- scripts/serve.mjs — сервер на стандартной библиотеке Node.
- scripts/build.mjs — сборка dist.
- .openai/hosting.json — статический хостинг без Site ID.

Юридические страницы — снимки документов на дату разделения. Актуальные тексты
регистрации версионируются в приложении; при изменениях синхронизировать копии.
Для нового проекта Codex скопировать всю эту папку и прочитать AGENTS.md.
Новый Site и публикация при разделении не создавались.

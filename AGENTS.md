# Point Landing — инструкции для Codex

Самостоятельный статический лендинг из экспорта Point, выделен 17.10.2026.
Сначала читать README.md. Соседнее приложение и история чата не нужны.

- Node >= 22.13.0, внешних зависимостей нет. npm run dev — 5173,
  npm run build — dist, npm start — просмотр dist.
- Разметка — pages/, ресурсы — public/. Не редактировать только dist.
- Адрес приложения — APP_URL в окружении/.env.local, см. .env.example.
  Не вшивать домен/localhost вручную в HTML.
- Лендинг не сохраняет регистрации и не предоставляет API. Регистрация,
  согласие, кабинет и маркетплейс принадлежат отдельному приложению.
- Калькуляторы работают только локально в браузере.
- Сохранять дизайн, тексты, адаптивность, языковую панель и PDF.
- Юридические HTML — копии; актуальные версии регистрации находятся в приложении.
- Не создавать symlink/импортов/зависимостей от соседнего проекта.
- После правок проверить сборку, ссылки, ресурсы и при возможности браузер
  на desktop/mobile. Согласие открывается на origin приложения.
- В hosting.json нет project_id. Для публикации выбрать/создать отдельный Site
  по заданию пользователя; не использовать ID исходного приложения.
